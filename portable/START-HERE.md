# Agent Delivery Team Packager — portable Chat package

This archive contains the same core instructions and knowledge used by the Custom GPT distribution.

When this archive is attached to a normal ChatGPT conversation:

1. Read `assistant/instructions.txt` first and use it as the working instructions for this conversation.
2. Use all files under `knowledge/` as the primary reference material for package templates, validation rules, prompt recipes, and GPT setup behavior.
3. `assistant/conversation-starters.md` contains suggested starting requests; they are examples, not additional rules.
4. Follow the user's current request when it conflicts with examples or defaults in the package.
5. Keep using these instructions and knowledge files throughout the conversation.
6. When creating or updating an agent delivery package, preserve the package contract described in the knowledge files and return downloadable files when file generation is available.

The source repository remains the source of truth for future package revisions.
